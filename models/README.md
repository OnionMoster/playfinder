# Recommendation Models

- `c-cf-mf/models/cf.py`: item-based collaborative filtering.
- `c-cf-mf/models/mf.py`: implicit ALS and BPR.
- `d-hybrid/models/hybrid.py`: PyTorch hybrid factorization model.
- `d-hybrid/models/cold_start_item.py` and `cold_start_user.py`: cold-start experiments.

The repository retains aggregate results and experiment configuration. Raw training data and model checkpoints are not included.
