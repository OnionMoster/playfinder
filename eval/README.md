# Evaluation

This directory contains the shared offline evaluation code, baseline implementations, aggregate metrics and comparison results. The main results are in `final_eval/` and `results/five-model-comparison.csv`. The evaluation uses a common temporal split and candidate policy; consult `docs/final-model-decision.md` for the scope and limitations of the comparison.

Raw user-level evaluation inputs are not included. Full reruns require the original processed data and relevant model artifacts.
